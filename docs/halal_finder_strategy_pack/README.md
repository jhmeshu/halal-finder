# Halal Finder — Strategy & MVP Pack

**Product promise:** Find halal. Check with confidence.

**Core description:** Halal Finder helps Muslims find halal food and check ingredients with greater confidence, wherever they are in the world.

This pack contains the product and business strategy, implementation roadmap, trust/data principles, testing plan, and the current MVP source.

## Important status note
The MVP is an early prototype, not a production service. It includes fictional sample businesses, local-only saved places, a basic ingredient keyword screen, and a barcode lookup integration that requires an internet connection. It does not yet have a shared database, live map, user accounts, moderation, camera scanning, payments, or verified business records. Do not represent sample businesses or example evidence labels as real.

`MVP-Chat-Preview.html` is a self-contained visual preview. The `MVP/` folder is the more complete installable-web-app scaffold with a manifest and service worker.

## Budget principle
Stay free-first. Do not buy a domain, pay for a map API, or subscribe to paid infrastructure until the prototype is reviewed and the next milestone is clear. A custom domain is optional for testing; secure public hosting is required for reliable installation and service-worker behavior.

15 · Guardrails

Do / Don’t

DoDon’t
Show “Not verified” proudly and clearlyHide unknown listings or pending states
Label sponsors on every paid unitLet payment UI resemble evidence UI
Downgrade expired certificates automaticallyOverride freshness manually in the UI
Use the five evidence badges verbatimInvent a sixth “Verified ✓” badge
Attribute Open Food Facts inlinePresent keyword hits as halal verdicts
Use Lucide icons consistentlyMix emoji into production chrome
Design RTL from tokensFlip left/right with a stylesheet afterthought
Quote sourced, translated versesDecorate with unsourced sacred text
